# 🖥️ My BSPWM Rice

A minimal yet aesthetic BSPWM setup powered by:
- **bspwm** – Tiling window manager
- **sxhkd** – Keybinding daemon
- **picom** – Compositor for transparency & animations
- **polybar** – Status bar
- **rofi** – App launcher
- **feh** – Wallpaper setter
- **dunst** – Notifications
